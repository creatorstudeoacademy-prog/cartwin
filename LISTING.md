# CartWin — Cart Recovery Popup — App Store Listing Pack

## 1. App name

**CartWin**

## 2. Tagline

Win back abandoning shoppers with exit-intent popups that offer the right nudge at the right moment.

## 3. Full description

**Most shoppers who add to cart never check out — and most never come back.**

CartWin detects when a shopper is about to leave with items in their cart and shows a beautifully designed popup offering a discount, free shipping, or a simple reminder. One recovered cart often pays for months of the app.

**Built for recovery:**
- Exit-intent detection on desktop, timed and scroll-based triggers on mobile
- Offer a percentage discount, fixed discount, or free shipping to seal the deal
- Discount codes generated automatically through Shopify — no manual code management
- Clean, mobile-first popup designs that match your brand

**Designed to convert, not annoy:**
- Smart frequency caps — never show the same popup twice in a session
- Full design customization: colors, text, images, button styles
- A/B testing ready: try different offers and see what wins

## 4. Key features

- Exit-intent popup triggered when shoppers move to leave with items in cart
- Timed and scroll-depth triggers for mobile shoppers
- Automatic discount code generation (percentage, fixed amount, or free shipping)
- Fully customizable popup design — colors, text, images, no code needed
- Frequency caps and smart display rules (no popup spam)
- Real-time recovery tracking — see recovered carts and revenue
- Mobile-responsive, fast-loading popup
